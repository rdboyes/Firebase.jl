Example

Firebase.firebase_linkuserinfo — Function

Example

data = firebase_signin("user@example.com","helloworld!!")

data = firebase_signin("ash@gmail.com", "hello!!123as")
firebase_linkuserinfo("user@example.com","helloworld!!",data["idToken"])
