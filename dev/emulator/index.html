Firebase Emulator Suite

Firebase.jl can talk to the local Firebase Emulator Suite instead of live Firebase, which is handy for tests and local development.

using Firebase

# Use the standard *_EMULATOR_HOST environment variables, if set
use_emulator()

# Or name services explicitly (true = default port on localhost)
use_emulator(firestore=true, database=true, auth=true, storage=true,
             project_id="demo-firebase")

# Switch every service back to live Firebase
use_production()

When a service is emulated, requests to it use the emulator's owner token, so no service-account credentials are needed. Services that are not emulated keep using live Firebase and your real credentials.

Firebase.use_emulator — Method
use_emulator(; host="localhost", firestore=nothing, database=nothing,
               auth=nothing, storage=nothing, project_id="demo-firebase",
               detect_env=true)

Point the package at the local Firebase Emulator Suite.

For each service you may pass an explicit "host:port" string, true to use the standard port on host, or leave it nothing. When detect_env is true, the standard *_EMULATOR_HOST environment variables are read for any service not given explicitly. If nothing is specified for a service and no env var is set, that service stays live.

Calling use_emulator() with no arguments enables every service whose env var is set, falling back to the default ports on host only for services you request.

Example

use_emulator()                                   # from FIRESTORE_EMULATOR_HOST etc.
use_emulator(firestore=true, database=true)      # localhost:8080 / localhost:9000
use_emulator(firestore="127.0.0.1:8080", project_id="my-demo")
